# 玄機閣 · BLE 电子罗盘（硬件套件）

传统罗盘的精度 + 数字的便利：ESP32 + 磁力计做成的小罗盘，蓝牙直连量宅 App，
实时把**倾角补偿后的航向角**推进网页（安卓 Chrome，Web Bluetooth）。

## 物料清单（约 30-50 元）

| 物料 | 数量 | 说明 |
|---|---|---|
| ESP32 DevKit V1 开发板 | 1 | 任何 30 针 CP2102/CH340 版本均可 |
| QMC5883L 磁力计模块 | 1 | 三轴磁，I²C |
| MPU6050 模块 | 1 | 加速度计，做倾角补偿（强烈建议，否则倾斜 10° 航向就偏） |
| 3.7V 锂电池（可选） | 1 | 移动使用；插着 USB 也行 |
| 杜邦线、开关、小盒子 | 若干 | 塑料/木质盒（**禁金属盒**，会屏蔽磁场） |

## 三步完成

1. **接线**：照 `wiring.svg` —— 两模块 VCC→3V3、GND→GND、SDA→GPIO21、SCL→GPIO22（I²C 共线）
2. **烧录**：Arduino IDE → 装.esp32. 开发板支持 → 开发板选「ESP32 Dev Module」→ 打开 `luopan_ble.ino` → 上传（零外部库）
3. **配对**：手机 Chrome 打开量宅 App → 罗盘页 → 「连接电子罗盘」→ 选 `XuanJi-LuoPan`

## 校准（必做一次，之后断电不忘）

**长按板载 BOOT 键 3 秒** → LED 快闪 → 手持罗盘在空中**画 ∞ 字持续 15 秒**（各方向都转到）→ LED 常亮即校准完成（自动存入 Flash）。

换环境（换了城市/附近铁器变化大）后重新校准一次。

## 输出协议

- 5Hz JSON 行：`{"h":123.4,"p":-2.1,"r":0.8,"c":1}`（航向/俯仰/横滚/已校准）
- 手机端指令（BLE 写入 RX 通道）：`D=7.5` 设置磁偏角（东偏为正，如北京约 -7°）；`CAL` 远程触发校准

## 精度预期与使用要点

- 认真校准后平持使用：±3° 以内；倾角补偿保证 ±30° 倾斜内航向稳定
- **远离金属**：配电箱、钢筋柱、手机本身（别和手机叠在一起测）、电脑音箱至少 1 米
- 测宅向的**正统方法**：屋中心 + 大门外七步 + 对角位，三处各读一次取平均；差 >15° 说明有干扰，取离干扰最远的一组
- 航向整体偏 180°：固件 `FLIP_Z` 改 1 重烧；恒定小偏差：用 `D=` 指令补磁偏角

## 与 App 的关系

连接后罗盘页读数直接来自硬件（顶栏按钮显示「电子罗盘 xxx°」），「记为朝向」照常使用；
后续 AR 页接入硬件航向也在计划内（`ios/` 与 `app/ar.html` 均可复用本协议）。
