# 卦牌 · 3D 打印说明

## 文件
| 文件 | 内容 |
|---|---|
| `guapai.py` | 参数化生成器（64 卦任选） |
| `卦牌_乾_01.stl` | 乾为天（六爻皆阳，六条整杠） |
| `卦牌_坤_02.stl` | 坤为地（六爻皆阴，六组断杠） |
| `卦牌_泰_11.stl` | 地天泰（下乾上坤） |
| `预览_*.svg` | 正视图预览（浏览器直接打开） |

## 生成任意一卦
```bash
python guapai.py --name 泰          # 按卦名
python guapai.py --index 1          # 按 King Wen 序号（1-64）
python guapai.py --bits 101010      # 按爻（自下而上 1阳0阴）
python guapai.py --name 乾 --scale 1.5   # 放大到 1.5 倍
```

## 打印参数建议
- **方向**：STL 已按最佳方向导出（背板贴床、爻面朝上），切片时不需要旋转
- **支撑**：不需要（无悬垂）
- **层高**：0.16 至 0.2mm（爻线浮雕高 2.2mm，细层高更清晰）
- **填充**：15%（约 25-30g PLA）；想沉手可用 30%
- **尺寸**：默认 92 × 109 × 33mm（宽×高×厚），缩放自由
- **进阶**：双色打印更佳——底座用金色 PLA，背板用朱砂红或墨黑，暂停换色在 z≈5mm（背板顶面）和 z≈30mm（底座顶面）

## 已验证
- 三角网格流形检查通过（每条边严格两侧配对，法线朝外）
- 有向体积为正（无翻面）
- z=0 平面贴床，无悬空层

## 设计
碑形背板圆拱顶，正面浮凸六爻（初爻在下、上爻在上，与卦象一致），朱框沿边，底座两层收边，正面嵌太极浮雕（含 S 线与双鱼眼）。整体与网站「玄機閣」同一套黄历美学。
