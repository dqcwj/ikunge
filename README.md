# 玄機閣 · 道家问卜与量宅项目

一个从网页问卜到手机量宅的完整传统文化项目。配色与美学统一为「黄历四色」：墨 `#2A2419` / 鎏金 `#8A6A2F` / 朱砂 `#9E2B20` / 宣纸 `#E9DDBC`。

## 项目结构

```

├── app\
│   ├── index.html      量宅 App（电子罗盘 / 画户型 / 形煞报告）
```

## 快速开始

| 目的 | 操作 |
|---|---|
| 打开主站 | 双击 `index.html`，或 `python server.py` 后访问显示的地址 |
| 手机用量宅 App | 电脑与手机同 Wi-Fi，`python server.py`，手机访问 `http://<电脑IP>:8000/app/` |
| 复验引擎测试 | `node fengshui.js`（94 项）、`cd app && node xingsha.js`（11 项） |
| 3D 打印卦牌 | 打开 `3d/` 下任意 `.3mf` 进 Bambu Studio 切片 |
| 生成任意卦 | `python 3d/jiaotai_bi.py --name 乾` |

## 安卓兼容说明

- **罗盘**：安卓 Chrome 用 `deviceorientationabsolute`（绝对 alpha），引擎已按事件类型甄别——相对方位事件一律忽略，不会污染读数；横屏时按 `screen.orientation.angle` 补偿。iOS 仍走 `webkitCompassHeading` + 授权流程，两平台共用一套处理。
- **PWA**：安卓 Chrome 访问 HTTPS 部署版会出现「安装到主屏幕」，装后离线可用（`app/sw.js` 缓存四件套）。
- **传感器前提**：与 iOS 相同，方向传感器只在 HTTPS（安全上下文）开放；局域网 HTTP 测试时用「手动定向」滑杆。
- **AR 扫房**：安卓无 RoomPlan 等价 API（截至 2026 年仍为社区功能请求），M3 LiDAR 扫房仅 iOS；安卓用「画户型」手动标记流程，判定能力一致。
- **字体**：安卓无楷体/宋体时回退 Noto Serif CJK / 系统衬线，版式略有差异但不影响功能。

## 部署到手机可用的 HTTPS（GitHub Pages）

iOS 的方向传感器只在安全上下文开放。要把罗盘自动读数用起来：

1. 在 GitHub 建一个仓库（如 `xuanjige`）
2. 把 `index.html`、`fengshui.js`、`app/` 推上去
3. Settings → Pages → 部署 main 分支
4. 手机访问 `https://<用户名>.github.io/xuanjige/app/`

## 规则考证说明

M1 的全部规则经多智能体并行考证（每题至少两个独立来源印证）+ 双路交叉校验：

- 命卦：立春分界；男 `11-数根` / 女 `4+数根`；余五男寄坤女寄艮（主流），1900-2099 逐年验证
- 八宅：变爻 XOR 法与大游年歌 64 格一致；矩阵对称；东四宅吉方必在东四位（体系自洽性已验证）
- 飞星：仅下卦（正针 ±4.5°），山向星顺逆查「入中星本宫同元龙」阴阳（非坐山本字，常见错法）
- 形煞：阈值（门冲 3m / 缺角 10%~20% / 开口 5m / 路冲 100m 等）来自可溯源来源，工程约定处已注明

八宅与飞星属不同流派，结论未必一致，产品中并陈展示。立春按 2 月 4 日近似，2 月 3-5 日出生者命卦可能有一年之差。

## 识物模型下载（一次性）

scan.html 的端上识别需要 COCO 模型权重（ssd_mobilenet_v2，17 分片约 68MB，Google 模型库）。直连被干扰时走本地代理：

    cd app/vendor
    python get_model.py                        # 直连尝试
    python get_model.py http://127.0.0.1:7897  # 走代理（Clash 默认混合口）

支持断点续传；未下载时识物页自动降级为手动勾选，不影响其他功能。
